Authentication

POST /api/v1/auth/login with JSON body:

{
  "username": "viewer",
  "password": "viewer123"
}

Returns a Bearer JWT token. Use it in the Authorization header:

Authorization: Bearer <token>

GraphQL

Visit /graphql for the interactive IDE, or POST queries to /graphql.

Introspection is enabled. Example query:

{
  __schema {
    queryType { name }
    types { name fields { name } }
  }
}

API Reference
REST API for model registry access (requires authentication)

Authentication

POST /api/v1/auth/login with JSON body to obtain a Bearer token:

{ "username": "viewer", "password": "viewer123" }

Use the token in the Authorization header:

Authorization: Bearer <token>

Viewer account (viewer/viewer123) can access public models only. Admin access requires the model-registry admin token (provisioned via Vault).

Endpoints

GET /healthz
Health check (no auth required)
GET /
API info / registry home (Accept: application/json for API response)
GET /api/v1/models
List all models (requires auth)
GET /api/v1/models/<name>
Model detail
GET /api/v1/models/<name>/versions
List model versions
GET /api/v1/models/<name>/versions/<version>
Version detail (with manifest). Private models require admin token.
GET /api/v1/models/<name>/versions/<version>/manifest
Get manifest only. Private models require admin token.
POST /api/v1/auth/login
Login (returns token + role)
Example: List Models
curl -X GET {{ registry_url }}/api/v1/models \ -H "Authorization: Bearer <token>"
Example: Get Model Manifest
curl -X GET {{ registry_url }}/api/v1/models/recommendation-v4-private/versions/v4/manifest \ -H "Authorization: Bearer <admin-token>"

Note: recommendation-v4-private is a private model. Admin token is required.

技术实施要点

在多个客户实施过程中，我们总结了以下最佳实践：

  • SSO 集成：所有客户均通过 SSO 实现统一身份认证。门户与 Console API 共用 SSO 客户端 （nm-portal-sso-prod），用户在门户登录后可无缝访问控制台。
  • API 域名规划：建议客户使用独立子域名部署 Console API（如 console.nebulamind.ai），与门户（www.nebulamind.ai）分离部署。
  • 租户隔离：每个客户分配独立租户 ID，数据在数据库、向量库、对象存储三层隔离。
  • 模型选择：金融行业客户倾向使用私有化部署的开源模型（如 Qwen、ChatGLM）， 其他行业客户多使用混合模型策略。

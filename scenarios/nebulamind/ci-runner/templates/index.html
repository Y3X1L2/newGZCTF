API 端点

CI 系统提供 REST API 用于项目管理和构建触发。部分接口需要认证。

GET /healthz - 健康检查 GET /api/projects - 项目列表 GET /api/projects/{id} - 项目详情 GET /api/projects/{id}/variables - 项目变量 (需要 token) POST /api/projects/{id}/trigger - 触发构建 (需要 token) GET /api/builds/{buildId} - 构建详情 GET /api/builds/{buildId}/logs - 构建日志

认证方式: Authorization: Bearer <token> 或 X-CI-Token: <token>

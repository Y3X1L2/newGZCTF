## 1 平台概况

隐喻平台用于安全培训、日常练习和赛事组织。教师在平台上安排课程、实验和课后练习，学员按章节学习，也可以进入题库独立练习。赛事组织者可以创建比赛、配置题目、管理参赛队伍，并查看提交记录和成绩。

平台把课程、题目和实验环境放在同一套系统中管理。使用者从网页进入相应业务，管理员集中维护账号、环境模板和执行节点。

| 使用场景 | 主要内容 | 使用结果 |
| --- | --- | --- |
| 培训课程 | 课程、章节、教学资源、实验和课后理论练习 | 学员完成学习任务，教师查看进度和成绩 |
| 自主练习 | 题库检索、题目附件、实验实例和答案提交 | 学员按自己的进度练习，保留做题记录 |
| 赛事组织 | 赛事配置、战队报名、题目、提交和榜单 | 组织者开展比赛，选手查看任务和比赛结果 |

### 页面入口

首页集中展示赛事、课程和公告。侧边导航提供赛事中心、自主练习、培训课程和战队协作入口；具有管理权限的账号还可以进入平台管理、环境模板和 TeamLab。

## 2 培训课程

教师可以按课程组织教学内容。每门课程包含简介、章节、资源和学习任务，学员报名后按课程安排学习。报名支持教师审核或自动通过，课程负责人可以添加共同授课教师。

### 课程内容

章节支持正文和视频，课程资源可以使用上传文件或外部链接。教师可以为章节配置实验题和理论练习，把知识讲解、动手操作和课后检查放在同一学习流程中。

实验题提供题面、附件和适用的运行环境。学员启动实验、完成题目并提交 Flag 后，平台记录结果。理论练习支持单选、多选和判断题，教师可设置通过线、答案展示和重新作答规则。

### 学习管理

课程详情展示章节状态和学习进度。教师可以查看学员报名情况、章节完成情况、实验结果和理论成绩，再打开单个学员的学习详情。

一门课程的常用准备顺序是：填写课程信息，编排章节，添加资源与实验，设置课后练习，检查学员视图，再发布课程并处理报名。

### 适用安排

培训班可由教师统一安排章节和考核；公开自学课程可使用自动报名，由学员自行完成任务。课程内容的编辑、学员管理和学习访问分别按账号角色及课程授权开放。


## 3 自主练习

自主练习提供独立题库。学员可以按题目名称、分类、难度、标签和完成状态筛选题目，查看题面、提示及附件。容器类题目可在页面创建实例，并显示访问入口、剩余时间和延期、销毁操作。

题目支持一次或多个 Flag 提交步骤。平台记录提交次数、判题结果和完成状态，并提供练习统计。教师可以管理练习题，并将符合条件的比赛题、培训习题和 AWDP 服务内容收录到题库。

## 4 赛事组织

赛事中心提供比赛介绍、赛程、报名和比赛工作区。选手通过战队参加比赛，在已开放的题目中完成任务、提交答案，并查看榜单。管理员负责题目、报名审核、赛区和公告。

CTF 比赛支持附件题、静态或动态 Flag，以及 Docker 和虚拟机环境。理论考试提供试卷、草稿保存、最终提交和成绩查看。AWDP 提供按轮次进行的攻击、修补、服务健康检查和结果记录。TeamLab 相关赛场提供网络场景、任务目标和运行环境入口。

## 5 环境与平台管理

平台通过环境模板和执行节点创建实验实例。管理员可以维护 Docker 镜像、虚拟机模板、节点和部署队列，查看任务进度、实例状态及运行日志。题目、课程实验和组网场景使用这些资源提供实际操作环境。

TeamLab 用于设计和运行多网段场景。管理员编辑网络拓扑、选择资产并发布版本，再按版本创建运行环境。运行页面提供资产状态、访问授权、流量观测、抓包及受授权的远程操作。开放 API 供外部系统接入资源管理和场景生命周期。

### 角色分工

| 角色 | 常用操作 |
| --- | --- |
| 学员和选手 | 参加课程、完成练习、组队报名、提交答案、查看个人结果 |
| 教师和出题人员 | 准备课程与题目、安排实验和理论练习、查看学员学习情况 |
| 赛事管理员 | 设置比赛、维护题目和赛区、审核报名、发布公告、查看比赛结果 |
| 平台管理员 | 维护账号、模板、节点、队列和系统设置，处理运行问题 |

### 使用条件

具体菜单与操作权限由账号角色、课程授权和赛事状态决定。课程、题目和实验环境由教师及管理员提前准备。Docker、虚拟机、AWDP 和 TeamLab 的可用范围，还取决于当前部署的节点能力、镜像和场景验收情况。

数字攻防联赛和 AI 教学接入属于后续建设内容，另行编制开发需求。

## 1 使用准备

使用浏览器打开管理员提供的平台地址，准备自己的账号。教师和管理员使用已授予相应权限的账号。报名课程或比赛时，按页面显示的报名规则申请；需要审核的申请通过后，进入学习或比赛工作区。

文中路径用于定位页面。例如 `/practice/browse` 表示在平台地址后进入该路径；课程和比赛详情中的编号使用实际页面地址中的编号。

## 2 登录与选择练习题

### 登录平台

入口：平台登录页 `/account/login`。

1. 在“用户名或邮箱”中输入账号，再填写密码。
2. 按页面提示完成安全验证，点击“登录”。
3. 进入平台后，从侧边导航选择“自主练习”“培训课程”或“赛事中心”。

已启用统一身份认证的部署，可以从登录页显示的门户入口进入。注册和密码找回入口按当前平台配置开放。

## 3 完成一次自主练习

### 启动与使用实例

入口：题目详情 `/practice/challenge/:id`。容器类题目显示“Docker 实例”区域，附件类题目按题面要求使用附件。

1. 阅读题面并下载需要的附件。
2. 在实例区域点击“创建实例”，等待状态从“调度排队”或“正在准备”更新为“运行中”。
3. 访问入口出现后，点击打开或复制入口，按题目要求操作。页面同时显示剩余时间。
4. 需要继续操作时，使用页面开放的延期按钮。完成后点击“销毁实例”，再查看实例状态。

> 截取：题目标题和实例区域，保留“运行中”、访问入口、剩余时间与操作按钮。
>
> 标注：①指向“运行中”；②指向访问入口旁的打开或复制按钮；③指向剩余时间。入口中的敏感地址按演示要求遮盖。

![S03 练习实例的访问入口](images/S03.png)

### 提交与查看结果

1. 在“提交 Flag”区域填写答案。题目包含多个步骤时，先选择本次提交对应的步骤。
2. 点击“提交”，等待判题提示。
3. 回答正确后，查看题目的完成状态；需要继续完成其他步骤时，切换到下一步。
4. 返回题库检查“已攻克”状态，或进入 `/practice/stats` 查看练习统计。

答案错误时，保留输入内容检查后再提交。提交异常时，先查看页面提示和网络状态，再重试。

## 5 学习章节与完成课后任务

### 阅读与实验

1. 打开章节，阅读正文并观看已配置的视频。
2. 在“章节实验”中打开实验任务，阅读题面，下载附件或创建实例。
3. 按要求完成操作并提交正确 Flag，返回章节检查实验完成数量。
4. 滚动到“章节完成”，查看阅读、必做实验和课后练习的完成条件。

满足条件后，点击“确认阅读并完成”或“标记章节完成”。状态更新后，可以进入下一章。

4. 查看得分和通过状态。教师开放重新作答时，页面显示“重新作答”；答案回顾按课程设置展示。

## 6 组建战队与报名比赛

### 创建或加入战队

入口：“战队协作” `/teams`。

1. 队长选择“创建战队”，填写战队名称与简介并保存。

3. 成员选择“使用邀请码加入”，输入邀请码后提交。公开战队也可通过搜索入口提交加入申请。
4. 在成员列表确认队长和队员信息，再按赛事要求安排报名。

## 8 参加理论考试

入口：理论或混合赛制比赛中的“理论考试”页面 `/games/:gameId/theory`。

1. 进入试卷，查看题目数量、总分和作答时间。
2. 通过题号切换题目，按单选、多选或判断题要求选择答案。
3. 作答过程中查看保存状态，需要时点击“保存草稿”。
4. 用答题导航检查已答和未答题目，补齐需要完成的答案。
5. 点击“最终提交”，核对确认窗口中的已答、未答数量，再点击“确认最终提交”。

最终提交后立即判分，答卷转为只读。多选题按完整答案判定得分。成绩和逐题答案按考试开放规则显示。

## 10 教学资源与学员管理

### 添加资源和实验

## 11 管理员创建比赛

### 设置比赛

入口：平台管理中的比赛管理 `/admin/games`。

1. 点击“创建比赛”，按“基本信息、赛制、报名与分组、时间与确认”的顺序填写。
2. 设置名称、摘要和比赛赛制，再设置队伍人数、实例数量、邀请码及报名审核方式。
3. 填写开始和结束时间，核对信息后创建比赛。建议准备阶段保持隐藏。
4. 进入“比赛信息”，补充比赛说明，检查时间、规则和公开状态；题目与报名配置就绪后公开比赛。
5. 根据组织安排维护“赛区管理”“比赛阶段”和“比赛公告”。

## 13 AWDP 与 TeamLab 专项赛场

## 14 模板 节点与运行任务

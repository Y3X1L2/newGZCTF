# YINYU vNext Phase 5B 赛事管理实施进度

更新日期：2026-07-15

## 1. 本批范围

本批只实现赛事管理的第一个完整纵向切片：

- `/admin/games`：赛事列表、当前页筛选、分页、创建和导入。
- `/admin/games/:gameId/info`：比赛信息、海报、导出、删除和保存保护。
- `/admin/games/:gameId/challenges`：CTF 题目列表、新建、启用和积分榜缓存刷新。
- `/admin/games/:gameId/challenges/:challengeId`：题面、计分、环境、附件、Flag、提示和测试实例。

阶段、赛区、报名审核、公告、理论试卷、AWDP 和渗透管理继续留在后续批次，不加载旧页面。

## 2. 契约结论

- 赛事列表仅支持 `count/skip`，当前没有服务端搜索、状态或赛制筛选。
- `GameInfoModel` 不包含报名人数、负责人和题目配置统计，首版不得伪造这些列。
- 创建比赛不会自动生成 AWDP 服务或理论试卷；对应模块应在后续专用页面显式配置。
- ZIP 导入接口直接执行导入，没有预检端点。首版只做文件名、类型、大小和显式确认，完整内容预检需要后端新增 dry-run API。
- 题目列表没有附件数和 Flag 数；完整信息只在进入题目编辑器后读取，避免列表 N+1 请求。
- 测试实例仅支持 Docker，创建和销毁均进入部署队列；Windows VM 测试实例需要后端补充管理接口。

- 写操作必须使用标题带 `vNext-Phase5B-Test` 的隐藏测试比赛。

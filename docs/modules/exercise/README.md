# 自主练习

自主练习面向希望在比赛之外持续解题的学员，也为教师提供公共题库维护入口。学员在练习目录按名称、分类、难度、标签、来源和完成状态筛选题目，进入详情后下载附件、启动所需环境并提交 Flag。平台按个人保存尝试、已解 Flag 和题目完成状态，学员可查看自己的练习统计。

教师可以新建、导入、编辑、启用或停用公共练习题，并维护附件、Flag 与镜像引用。题目来源可关联比赛、培训或攻防素材，导入后以公共题定义、个人实例和练习提交保存练习事实。动态题使用当前用户实例的独立 Flag，管理员预览值仅用于预览。

```mermaid
flowchart LR
  A[教师维护公共题库] --> B[学员筛选分页目录]
  B --> C[读取题目与个人状态]
  C --> D[附件或独立运行实例]
  D --> E[提交 Flag]
  E --> F[记录尝试与完成情况]
```

课程也复用 Exercise 的题目与实例执行能力。属于课程的题目是隔离快照，在课程内访问；公共浏览、公共管理与外部练习接口处理公共题，课程权限、额度和提交归培训模块。公共练习容器额度按公共练习实例统计，开启既有自动清理策略时，清理范围也限于公共练习。

练习浏览和管理目录采用服务端分页，默认每页20题，最多100题。后端先检查可见范围和筛选条件，再查询当前页；总数、启用题数和容器题数按全部匹配题计算，标签选项跨页稳定。旧数组接口为兼容保留，个人统计页仍使用这些接口读取完整统计所需的数据。接口参数和标签查询条件见[分页参考](reference/catalog-pagination.md)。

练习应用服务负责业务查询、提交和题库写入，运行底座执行环境任务，具体链路和定向测试见[开发页](development.md)。核心练习验收已有用户确认，10月11日也记录了分页接口与页面的发布验收。各题目镜像、内容运营和故障场景按实际环境继续核验，当前范围见[状态页](../../current-state.md)。

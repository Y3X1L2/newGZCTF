## 什么时候建记录

跨会话、多模块、多人配合或涉及迁移/部署的任务，在开始时复制 [任务模板](task-template.md)，命名为 `YYYY-MM-DD-<task>.md`。写清目标、基线、分工、关键决定、测试、下一步；计划和结果都更新同一份文件。简单修改在PR里说明即可。

有首个有意义的提交后建立Draft PR，持续更新到可审查，再转Ready。PR负责讨论与审查，任务记录负责接手，两者相互链接，不复制整篇过程。仓库权限和任务授权仍决定谁可以合入或部署。

完成后将稳定行为写回模块/手册，遗留事项放到 [backlog](../backlog.md)，将记录标为完成并移出活动入口。保留发布身份、备份、恢复、失败和回退证据；旧数字、环境和一次性授权仅属于记录时点。

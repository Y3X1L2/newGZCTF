# 组网页面布局调整

状态：已验收、合入 `main` 并部署主站。负责人：Codex。

## 目标与基线

- 页面更宽，列表和详情随内容向下展开，减少页面里的多层滚动条。
- 保留 Netlab 组件能力，按钮、字体、间距跟随平台；避免大片绿色。
- 基线：`origin/main` 的 `af56a683`；本地分支：`codex/teamlab-page-layout`。
- 使用主工作区 `D:\Work\newGZCTF`，没有新建 worktree。
- 本地验收期间没有推送或部署。用户验收通过后，授权合并整个布局分支并发布主站 `.27`，部署只涉及主站前端；Netlab 执行面不在发布范围内。

## 已调整

- 去掉工作区外层固定高度和重复边框，利用平台现有内容宽度。
- 资产列表、对象详情、模板目录自然展开。按最新验收意见，控制台、SSH、串口和 RDP 改为新浏览器标签页，移除底部连接区及其折叠、多连接切换状态。
- 小屏幕自动换行。宽表格在小屏幕保留必要的横向滚动。
- 拓扑中普通滚轮滚动页面，按住 Ctrl 才用滚轮缩放拓扑，原有缩放按钮保留。
- 卡片以中性色为主，链接和图标用蓝色，绿色用于运行状态；主要按钮跟随平台。
- 用户二次验收后，环境统计卡片改为完整边框选中，去掉顶部单条色线。
- 修复运行任务抽屉被页面动画容器推到屏幕外的问题：弹层挂到独立的页面顶层容器，保留组网局部主题和样式；补齐关闭按钮名称。
- 修复任务下拉菜单背景透明导致叠字：主题容器放到样式作用域内部，表单和菜单共用修复；没有给任务下拉框增加专用覆盖样式。
- 继续复用 Mantine、React Flow、noVNC 和 xterm；未替换它们的业务能力。
- 资产页取消重复对象栏，增加资产/网段切换并保留路由器入口。流量概览保留全部机器曲线；图例改为单机聚焦，再次点击恢复全部。点击通信图里的机器或连线，画布同步收窄、聚焦，右侧立即显示相关报文；卡片右上角可关闭，选中提示留在通信图标题处。
- 报文列表与详情弹窗继续复用原组件；详细筛选、导出和告警保留二级入口。概览随页面向下滚动，旁侧报文卡片内部滚动，避免选中机器后页面高度突变。小屏幕上下排列，详情弹窗切换协议层/原始字节。删除旧多栏拖动、移动端分栏状态和多余入口。

- 最新验收调整移除拓扑左侧常驻列表，视图切换旁增加轻量“定位对象”：输入名称、IP 或网段搜索，空查询仅显示最近 4 项或提示，移除分类与完整目录；复用当前工作区数据与 Mantine 键盘选择能力。工具栏放在画布和检查器上方，详情收放不挤动入口。右侧详情 8 像素短距离滑入加淡入，进入 180 毫秒、退出 160 毫秒；画布边界以 100 毫秒快速过渡，内容固定靠右，已打开后切换对象不播放动画。手动选中只更新属性，只有定位入口可以移动画布。定位浮层不显示滚动条，保留滚动操作；不增加节点临时强调效果。

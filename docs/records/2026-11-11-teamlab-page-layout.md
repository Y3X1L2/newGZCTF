## 已调整

- 去掉工作区外层固定高度和重复边框，利用平台现有内容宽度。
- 资产列表、对象详情、模板目录自然展开。按最新验收意见，控制台、SSH、串口和 RDP 改为新浏览器标签页，移除底部连接区及其折叠、多连接切换状态。
- 小屏幕自动换行。宽表格在小屏幕保留必要的横向滚动。
- 拓扑中普通滚轮滚动页面，按住 Ctrl 才用滚轮缩放拓扑，原有缩放按钮保留。
- 卡片以中性色为主，链接和图标用蓝色，绿色用于运行状态；主要按钮跟随平台。
- 用户二次验收后，环境统计卡片改为完整边框选中，去掉顶部单条色线。
- 修复运行任务抽屉被页面动画容器推到屏幕外的问题：弹层挂到独立的页面顶层容器，保留组网局部主题和样式；补齐关闭按钮名称。
- 修复任务下拉菜单背景透明导致叠字：主题容器放到样式作用域内部，表单和菜单共用修复；没有给任务下拉框增加专用覆盖样式。
- 继续复用 Mantine、React Flow、noVNC 和 xterm；未替换它们的业务能力。
- 根据最新验收意见，资产页取消重复对象栏，增加资产/网段切换并保留路由器入口。流量概览保留全部机器曲线和整行通信图；图例改为单机聚焦，再次点击恢复全部。报文与告警放入二级视图，报文详情使用宽弹窗，小屏切换协议层/原始字节。删除旧多栏拖动和移动端分栏状态。
- 流量概览和报文列表随页面向下滚动；宽报文表保留必要的横向滚动，详情弹窗、文件区和终端各自保留操作区域。

## 本地验证

- TypeScript、TeamLab 定向 lint、前端架构检查、Vite 生产构建通过。
- 浏览器检查了 390、1366、1920、2560 宽度和日夜主题。
- 模板目录、资产列表与详情未出现内部纵向滚动；页面没有横向溢出。
- 实测在拓扑区域滚轮向下操作时，页面向下滚动；控制台改为独立页面后，原工作区不再显示连接区。
- 二次验收复现了抽屉裁切；修复后在上述四档宽度确认任务抽屉完整位于视口内，无横向溢出，关闭按钮可用，并检查 VPN 抽屉。
- 独立控制台和 API adapter 共 7 个定向测试通过，覆盖连接权限、无效协议、SSH 设置取消/重开/保存及比赛入口范围。浏览器验证新标签页打开、SSH 设置弹窗、串口页、任务下拉菜单和演示面板。
- 本次分层调整增加曲线单机切换、报文键盘选择两项定向测试；浏览器核对机器筛选、二级入口、弹窗、网段清单及宽窄屏。预览只验证交互，真实流量查询、导出及告警采集仍需上线授权后的基础设施验收。
- 未运行完整前后端测试：改动限于布局、主题和控制台前端入口，没有修改后端 API、数据或执行逻辑。
- 按用户要求，本地样例服务补充 CPU/内存/网络/磁盘曲线、通信关系和报文详情；页面标题标明“本地演示数据”，样例代码留在仓库外。
- 没有连接生产环境；真实 VNC/SSH/串口会话、流量采集和文件操作未在本次验证。控制台的连接中断提示来自预览未提供实际连接。

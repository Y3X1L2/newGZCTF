# TeamLab 接入 Netlab

## 目标与边界

基线为远端 main `ce1ef4ec`。上层保留用户、比赛、队伍、目标、Flag、计分与重建规则，通过底座原有 API 完成组网。验收聚焦调用链、权限和界面；生产与现有数据保持原状，数据搬迁安排在上线窗口。

用户确认直接迁移前端源码，使用管理员签发的普通服务 Token。底座的 Token 扩展、权限委托及嵌入模式已撤回，底座候选仅保留通用虚拟机初始化文件能力。

## 当前实现

- 管理员填写底座地址、已授权项目和服务 Token。Token 由上层加密保存，浏览器沿用上层登录。
- 上层入口检查教师资源归属和比赛队伍绑定；底座收到普通 Bearer Token。环境使用底座原有 `externalReference` 保存创建者或比赛关联。
- 画布、模板、终端、流量和存储组件迁入上层 React 页面，随上层构建；HTTP、SSE、上传下载和 WebSocket 使用同一个 API 前缀。
- 底座实际权限决定可用操作。镜像导入及节点、存储管理写操作使用底座原有管理员界面。
- 比赛环境使用底座生命周期 API；上层保留创建请求标识、重建次数与业务绑定，销毁完成后清理本地关联。
- 旧执行链、调度 worker、页面和专属测试已移除。历史实体及镜像引用保留供上线迁移核对，普通 CTF、培训和 AWDP 继续走原 Runtime/Agent。

源码定位与长期契约统一维护在 [开发地图](../modules/teamlab/development.md) 和 [接入手册](../modules/teamlab/netlab-integration.md)。

## 已执行验证

- 上层定向调用链测试 15/15：真实 HTTP/WebSocket 代理 14 项、真实 PostgreSQL 业务链 1 项。覆盖前向迁移、历史绑定、创建复用、Flag 隔离、重建重试、销毁确认及访问撤销。
- 实际 Controller 路径验证选手跨队访问和启停被拒绝、本队详情隐藏初始化参数、场景创建绑定配置项目与当前创建者。
- 测试响应缺少契约必填 `view` 字段导致首次失败，补全测试数据后上述 15 项通过。
- 底座 `0b18523` 的 verify CI 通过；相对 main 仅 13 个虚拟机初始化文件相关文件变化，Go 定向测试和命令构建通过。
- 前端完整门禁通过：locale、lint、TypeScript、架构、225 项单元测试、生产构建与制品预算。随后删除 17 个不可用管理文件和 28 个无调用 API 方法，定向复验类型、lint、架构、2 项 API 测试、构建和预算均通过。
- 上层生产构建配合隔离 API 测试数据，完成 1366/1920/2560 像素日夜主题及列表、模板、编辑、流量、性能页面检查，页面错误与水平溢出均为零。按用户要求后续验收限定桌面；标题与内容区沿用上层留白。
- 最终源码迁入为 `f30d6735`，后端调用链修正为 `f559da24`。本轮临时 PostgreSQL 和前端预览服务已停止并清理，常驻数据库保持运行。

底座真实 VM 的 QGA 文件初始化与生产数据搬迁随上线验收，本轮通过隔离 PostgreSQL 与 HTTP 执行边界验证上层调用链。最终分支 CI 结果在本次 PR 保留。

## 候选与上线

- 关闭访问撤销 VPN 与发布服务，逐项读取底座操作终态；失败入口保留重试按钮，现有后台清理任务继续撤销。选手创建入口与关闭访问共用比赛锁。

- 批量准备、单队部署、切换场景版本和修改目标共用原有比赛配置锁，租约丢失时取消当前请求。

- 本轮真实 PostgreSQL 与 HTTP/WebSocket 定向测试 16/16，通过部署期间修改目标、关闭期间创建 VPN、撤销失败后后台重试、角色边界和日志传输验证。前端重试交互 2/2，类型、lint 与架构检查通过，后端构建为零警告、零错误。测试请求流复用与命名冲突已在测试代码修正，前端依赖按锁文件补齐。全量门禁由 PR CI 执行。

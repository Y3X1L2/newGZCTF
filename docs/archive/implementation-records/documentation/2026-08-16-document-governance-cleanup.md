# 2026-08-16 文档治理清理记录

本文记录本轮文档治理的范围、判定规则和验收结果。它属于实施记录，不是现行开发规范；当前文档入口始终以 `docs/README.md` 为准。

## 1. 目标

- 现行目录只保留能够指导当前代码开发、部署、使用和验收的文档。
- 已完成的 Phase、计划、进度、审查、基线和一次性修复记录统一归档。
- 已被替代且只会诱导错误操作的文档直接删除，历史内容仍可通过 Git 追溯。
- 现行说明统一使用简体中文，代码标识、API 路径、命令和协议名称保留原文。
- `docs/development/current-state.md` 只保存当前事实和未闭环事项，不再追加会话流水。

## 2. 分类规则

| 分类 | 处理方式 | 判定标准 |
| --- | --- | --- |
| 现行规范与契约 | 保留并核对源码 | 模块边界、API、事件、Agent、前端边界等仍约束当前实现 |
| 功能说明 | 保留并更新 | 面向使用者或维护者解释当前已经存在的功能 |
| 运维手册 | 保留并验证 | 当前部署、节点、镜像、网关、VM、恢复和验收仍会执行 |
| 当前状态 | 重写并保持精简 | 只记录代码、生产、验收和缺口的当前事实 |
| 实施记录 | 移入 `docs/archive/implementation-records/` | Phase、Plan、Progress、Review、Acceptance、Baseline、日期化任务记录 |
| 误导性旧入口 | 删除 | 已被新手册替代、只承担旧链接跳转或描述废弃运行路径 |

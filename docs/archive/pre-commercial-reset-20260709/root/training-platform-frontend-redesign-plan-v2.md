# YINYU 培训平台前端产品化重构计划 v2

## Summary

本计划用于指导培训模块下一轮前端重构。目标不是简单修补当前课程列表页，而是把培训模块从“课程卡片 + 弹窗表单”升级为成熟的在线培训平台：学生端强调学习路径、个人进度和章节内实验；教师端强调课程建设、章节编辑、报名审核和分组学情；管理员端强调全局治理、资源与权限闭环。

设计参考方向：

- 学习通 / 超星：课程、章节、任务点、学情统计、签到、教师管理。
- Moodle / Canvas / Blackboard：模块化课程、完成规则、学生进度、教师分析。
- 飞书云文档：左侧文档树、中间大编辑区、右侧属性与协作面板、Markdown 与富内容编辑体验。

本轮重点是前端体验和交互重构，后端接口尽量复用现有课程、章节、题目、报名、分组、统计接口。只有个人学习总览、平台级签到等当前确实缺失的数据能力，才作为小范围接口补齐。

## Product Goals

1. 学生进入培训模块后，能立刻知道今天该学什么、已经学到哪里、哪些章节/题目没完成。
2. 教师能够像使用文档平台一样编辑课程内容，而不是在小弹窗里写长 Markdown。
3. 课程方向、课程章节、实验题、资源、视频、完成规则、报名审核、分组可见性形成闭环。
4. 培训模块视觉与 YINYU 管理界面保持统一：管理界面同款背景、毛玻璃卡片、渐变状态文字、无蜂巢噪点。
5. 不做前端空实现。所有可点击、可统计、可配置功能必须有对应接口或明确的阶段性降级策略。

## User Roles And Views

### 学生

学生只能看到自己的学习内容与进度：

- 培训首页
- 我的课程
- 可报名课程
- CTF 培训方向
- 理论培训
- 课程详情
- 章节阅读
- 章节内实验容器卡
- 个人学习数据面板
- 平台级签到入口

学生不能看到课程编辑、分组管理、报名审批、全量学情统计等教师/管理员能力。

### 老师

老师可以管理自己创建或被授权的课程、分组和学生：

- 教师培训工作台
- 课程建设
- 章节编辑
- 报名审核
- 课程可见范围配置
- 学生分组学情查询
- 自己分组内学生学习轨迹
- 课程资源与章节实验配置

老师不能查看或管理其他老师无授权课程，也不能查看管理员/超级管理员管理能力。

### 管理员

管理员拥有全局培训治理能力：

- 全量课程
- 全量分组
- 全量学生学情
- 培训资源与镜像模板治理
- 老师课程授权
- 全局报名与发布状态审计

管理员不管理超级管理员和同级管理员权限。

### 超级管理员

超级管理员拥有最高权限：

- 管理员能力全集
- 权限组治理
- 全平台培训配置
- 全局资源、课程、日志审计

## Information Architecture

### 学生端导航结构

学生培训页采用三层学习导航：

```text
培训
├── 我的课程
├── 最近学习
├── CTF 培训
│   ├── Web
│   │   ├── 信息搜集
│   │   ├── SQL 注入基础
│   │   └── 文件上传
│   ├── Misc
│   ├── Crypto
│   ├── Pwn
│   └── Reverse
└── 理论培训
    ├── 安全基础
    ├── 网络协议
    └── 法规与规范
```

方向必须支持自定义，由老师或更高权限在培训管理中维护。

### 教师端导航结构

教师端分为三个主入口：

```text
教师培训工作台
├── 教学总览
├── 课程建设
│   ├── 课程列表
│   ├── 课程编辑
│   ├── 章节编辑
│   ├── 资源管理
│   └── 实验题配置
├── 报名审核
└── 分组学情
```

### 管理员端导航结构

管理员端在教师端基础上增加治理维度：

```text
培训治理
├── 全量课程
├── 全量分组
├── 全量学生学情
├── 教师授权
├── 资源与模板
└── 审计日志
```

## Student Experience

### 培训首页

布局采用 `左侧导航树 + 中间学习内容 + 右侧个人面板`。

左侧：

- 我的课程
- 最近学习
- CTF 培训方向树
- 理论培训方向树
- 已完成

中间：

- 继续学习：最多展示 2 个重点课程或章节。
- 今日任务：未完成章节、待完成实验、待完成理论测验。
- 我的课程：展示已报名或已分配课程。
- 可学习课程：展示可报名课程。

右侧：

- 今日签到
- 连续签到天数
- 本周学习时长或学习行为次数
- 课程完成率
- CTF 完成题数
- 理论正确率
- 近 7 / 30 日学习曲线
- 未完成任务列表

### 课程卡片

当前课程卡片存在封面区域过空、信息密度低、状态组件像胶囊按钮的问题。新卡片采用紧凑信息架构：

- 状态：使用渐变文字，例如 `可学习`、`待审核`、`草稿`、`已归档`。
- 类型：无胶囊文字标签，例如 `WEB · CTF · 入门`。
- 标题：大字号，支持两行截断。
- 摘要：两行以内。
- 教师：教师名或团队。
- 进度：`3/12`、进度条、最近学习章节。
- 操作：进入课程 / 继续学习 / 申请报名。

课程卡片不使用蜂巢背景，不使用噪点层，不使用过大的空封面区域。

### 课程详情

课程详情采用三栏：

- 左侧：章节目录树。
- 中间：课程介绍、章节内容、视频、Markdown 正文、实验题卡。
- 右侧：课程进度、资源、完成规则、报名状态。

章节目录项展示状态：

- 未开始
- 学习中
- 已完成
- 有未完成实验
- 理论测验未通过

完成状态用小图标和渐变文字，不用胶囊。

### 章节学习页

章节页采用类文档阅读布局：

- 顶部显示课程名、章节名、当前完成状态。
- 中间显示 Markdown 正文。
- 正文支持：
  - 标题目录
  - 代码块
  - 图片
  - 表格
  - 提示块
  - iframe 视频
  - 附件资源
  - 容器题卡片

删除“练练手跳转”设计。实验题直接嵌入章节末尾，学生在当前章节内：

- 创建容器
- 查看入口
- 复制访问地址
- 下载附件
- 提交 Flag
- 查看是否完成

第一版容器题卡统一自动聚合在章节末尾。后续可扩展为 Markdown 占位符，例如：

```markdown
:::challenge id=123
:::
```

这样既保证第一版稳定，又为正文任意位置插入实验卡预留空间。

## Teacher Experience

### 教师培训工作台

教师进入培训模块后，默认看到教学工作台，而不是课程列表表单。

核心区域：

- 待审核报名
- 今日学习人数
- 分组平均完成率
- 低活跃学生
- 最近 Flag / 理论提交
- 待发布课程
- 待完善章节

教师可以从这里进入课程建设、报名审核和分组学情。

### 课程编辑工作台

课程编辑对标飞书云文档，采用工作台布局：

```text
顶部固定栏：返回 / 保存 / 预览 / 发布 / 可见范围 / 更多

左侧：课程树
  课程概览
  章节 1
  章节 2
  资源
  实验题

中间：大编辑区
  Markdown 编辑器
  视频 iframe
  资源插入
  提示块
  代码块
  容器题卡占位

右侧：属性面板
  标题
  摘要
  发布状态
  排序
  完成规则
  可见分组
  绑定题目
  默认环境模板
```

不再使用小弹窗编辑长 Markdown。弹窗只用于短操作，例如确认删除、快速新建资源、选择题目。

### Markdown 编辑器

编辑器以 Markdown 为主，但要支持类飞书体验：

- 大尺寸编辑区域。
- 左侧章节树常驻。
- 顶部工具栏插入常用块。
- 支持 iframe 视频。
- 支持插入附件资源。
- 支持插入提示块。
- 支持插入容器题卡引用。
- 支持预览模式。
- 支持保存状态提示。

iframe 视频建议设置白名单策略：

- B 站
- 飞书
- 腾讯课堂
- 学校内部域名
- 管理员配置的额外白名单

如果第一阶段不改后端白名单，可先在前端提示“仅允许管理员配置的可信嵌入源”，后续补安全校验。

### 报名审核

保留老师审核报名。

报名审核应有独立列表：

- 学生姓名
- 学号
- 所属分组
- 申请课程
- 申请理由
- 申请时间
- 审核状态
- 通过 / 拒绝

课程详情内也显示当前课程报名申请。

### 分组学情

教师只看自己管理的学生分组。

分组学情展示：

- 分组平均完成率
- 分组签到率
- 低活跃学生
- 课程完成分布
- CTF 题目完成数
- 理论正确率
- 未完成模块 Top

点击学生进入学生详情：

- 已加入课程
- 每门课程进度
- 已完成章节
- 未完成章节
- 容器开启但未解出的题
- 理论错题或未通过模块
- 最近学习行为

## Admin Experience

管理员培训治理台展示全量数据：

- 总课程数
- 已发布课程
- 草稿课程
- 今日学习人数
- 今日签到人数
- 全局完成率
- 老师课程分布
- 分组学情排行
- 资源模板状态

管理员可管理全部课程、全部分组、全部学生和老师授权。超级管理员额外管理权限组。

## Completion Model

章节完成规则：

```text
章节完成 =
  阅读确认完成
  AND 所有必做容器题完成
  AND 必做理论测验达到通过率
```

课程完成规则：

```text
课程完成 =
  所有必修章节完成
```

学习状态：

- 未开始：没有阅读、没有提交、没有容器记录。
- 学习中：有阅读或容器启动或提交行为，但未满足完成规则。
- 已完成：满足完成规则。
- 阻塞：有必做实验或理论测验未通过。

状态展示必须让学生知道“卡在哪里”，例如：

- 还需完成 2 个实验
- 理论测验正确率未达 80%
- 章节阅读未确认

## Platform-Level Check-In

签到为平台级，不绑定单课程。

学生端：

- 今日签到按钮。
- 连续签到天数。
- 本月签到日历。
- 近 7 / 30 日学习曲线。

教师端：

- 分组签到率。
- 未签到学生。
- 连续低活跃学生。

管理员端：

- 全平台签到趋势。
- 分组/老师维度统计。

接口建议：

- `GET /api/training/me/overview`
- `POST /api/training/checkins`
- `GET /api/training/checkins/me`
- `GET /api/admin/training/groups/{groupId}/checkins`

如果接口暂未实现，前端第一阶段只显示无签到数据的正式空态，不能伪造数据。

## Visual Design

### 背景

培训模块统一使用管理界面同款背景，不再使用蜂巢背景。

页面容器应从左侧导航右边缘开始铺满视口，不出现截图中的横向溢出和右侧空白。

### 状态

状态组件统一使用渐变文字：

- 可学习：绿色渐变。
- 待审核：紫色渐变。
- 草稿：银灰渐变。
- 已归档：灰白渐变。
- 未通过：红色渐变。
- 已完成：绿色渐变。
- 学习中：青绿渐变。

不使用胶囊边框。

### 标签

课程标签不使用胶囊。采用轻量文字形式：

```text
WEB · CTF · 入门
```

或小型前缀：

```text
# WEB
```

### 卡片

所有培训卡片统一为毛玻璃卡片：

- 半透明深色底。
- 细边框。
- 轻微内高光。
- 无噪点。
- 无蜂巢。
- 无大片空白封面。

### 布局比例

学生首页：

```text
左侧导航：16rem - 20rem
中间内容：自适应，占主要空间
右侧面板：18rem - 24rem
```

教师编辑页：

```text
左侧课程树：18rem - 22rem
中间编辑器：自适应，占主要空间
右侧属性面板：20rem - 26rem
```

小屏幕下三栏折叠为：

- 顶部切换标签。
- 左侧树进入抽屉。
- 右侧属性进入抽屉。

## Quality Gates

### Visual QA

- 1366x768 不横向溢出。
- 1920x1080 页面饱满但不拥挤。
- 2K 屏中内容不会过度拉伸。
- 移动端三栏合理折叠。
- 无蜂巢背景残留。
- 无噪点卡片残留。
- 无胶囊状态残留。
- 无乱码中文。

### Interaction QA

- 学生可完成完整路径：报名 -> 审核通过 -> 学习章节 -> 启动容器 -> 提交 Flag -> 完成章节 -> 完成课程。
- 老师可完成完整路径：建课 -> 建章节 -> 写内容 -> 插视频 -> 配资源 -> 配实验题 -> 设置可见分组 -> 发布 -> 审核报名 -> 查看学情。
- 管理员可查看全局课程和学生培训情况。

### Permission QA

- 学生不看到教师管理入口。
- 老师只看到自己授权课程和分组。
- 管理员看到全量培训数据。

# YINYU vNext 生产升级验收报告

## 1. 验收结论

截至 2026-07-20，数据库副本迁移与恢复、通用管理写操作、本地登录、CTF 核心判题与运行环境、独立理论考试、培训报名与理论作业均已完成真实接口验收。

当前结论为：**尚不具备直接替换 `10.24.0.27` 现网后端的条件**。

上线前仍有三个必须补齐的验收项，以及一个已经完成前端短期缓解但仍应完善后端契约的运行时风险：

1. 公网容器入口存在约 5 秒的映射同步窗口；vNext 已为新建 Docker 实例增加 8 秒不可点击准备状态，但 API 仍缺少真实网关就绪信号。
2. AWDP 完整流程按要求改为测试人员浏览器手工验收，结果尚未回填。
3. IAM 缺少本轮新签发的有效门户 Token，实时成功 SSO 尚未重新执行。
4. 本机未运行 Docker，Testcontainers 集成测试尚未在完整本地环境重跑。

原有 NuGet 高危和中危公告已通过补丁级升级处置，当前生产项目漏洞扫描结果为 0。

本轮未重启、未升级、未替换 `10.24.0.27:8080` 现网服务。

## 10. 上线阻塞项与已缓解风险

### 10.1 P1（短期已缓解）：公网入口发布早于映射就绪

当前部署采用外部公网网关拉取模式：

```text
10.24.0.27 API 返回 Running 和公网入口
        ↓
203.195.157.191 每 5 秒拉取 /api/internal/port-map
        ↓
更新 Nginx stream 配置并 reload
```

真实诊断结果：

- WireGuard 持续握手正常，控制面隧道地址为 `10.250.0.2`，公网网关为 `10.250.0.1`。
- 网关同步服务和 Nginx 均处于运行状态，配置语法正确，监听 `30000-30059`。
- 实时映射为 `30000 -> 10.24.0.30:42762`。
- 网关直连 upstream 返回 `401`，网关本机代理返回 `401`，外部访问公网入口也返回 `401`。
- 从 API 返回 `Running` 到公网入口首次可达实测为 `5.32` 秒。
- 实例销毁后动态映射已自动清空。

因此不存在持续网络中断。vNext 已对比赛和培训的新建 Docker 实例统一增加 8 秒准备状态，同步期间不渲染复制和打开入口；浏览器已验证倒计时结束后自动开放，验收脚本最多轮询 30 秒。该措施已关闭当前用户直接点击到 5 秒窗口的短期风险，但它仍是时间型缓解；后端后续应提供网关同步确认或健康就绪状态，以覆盖网关 reload 延迟超过 8 秒的异常场景。

### 10.2 已关闭：NuGet 依赖安全风险

高危 `MessagePack` 与 MailKit、OpenTelemetry 中危公告均已通过补丁级升级关闭，当前漏洞扫描为 0。编译和 485 项单元测试已通过；离线预发布环境仍需执行 Redis 实时广播与遥测导出冒烟测试。

### 10.3 P1：AWDP 当前版本人工验收未完成

测试组必须回填 AWDP 手工验收表，至少提供双队实例、攻击得分、补丁双验证、重置、恢复、停止和资源清理证据。

### 10.4 P1：IAM 实时成功链路待补

取得当前有效门户 Token 后，执行一次门户进入 GZCTF、自动登录、既有账号绑定和新账号创建测试，并确认 `returnUrl` 白名单行为。

### 10.5 P1：完整集成测试环境待补

在 Docker 可用的 CI 或专用测试机重跑 236 项 Testcontainers 测试。必须区分环境初始化失败、真实断言失败和跳过，不能仅以进程退出码代替测试分析。

## 11. 下一阶段建议

1. 后端补充公网网关同步确认或健康就绪状态，替代当前已上线验收通过的 8 秒前端准备窗口。
2. 在离线预发布环境回归 Redis SignalR backplane、实时榜单、AWDP 状态推送和 OpenTelemetry 导出。
3. 由测试组执行 AWDP 手工验收并回填结果。
4. 使用新 IAM Token 完成实时 SSO。
5. 在 Docker 可用环境运行完整 236 项集成测试。
6. 所有阻塞项关闭后，再按维护窗口执行 `10.24.0.27` 一次性切换、健康检查和回滚演练。

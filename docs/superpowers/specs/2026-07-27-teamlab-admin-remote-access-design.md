# TeamLab 管理员远程运维设计

## 1. 目标

管理员能够从平台网页进入任意比赛、任意队伍环境中的具体资产：

- 容器使用网页终端。
- Linux 虚拟机使用网页 SSH。
- Windows 虚拟机使用网页 RDP。

访问过程不得向选手开放新的入口，不得向浏览器泄露资产密码、私钥、计算节点地址或转发端口，并且必须完整记录操作人员、目标资产、会话过程和结束原因。

## 2. 范围

本功能只访问 TeamLab 场景中的容器和虚拟机，不提供物理计算节点登录能力。

本轮不实现：

- 本地 SSH 或 RDP 客户端直连。
- 管理员专用 VPN。
- 虚拟机显示控制台。
- 额外的虚拟机运维网卡。
- 面向选手的远程运维入口。

## 3. 权限规则

- 超级管理员和管理员可以访问全部比赛、队伍和资产。
- 比赛所有者可以访问自己比赛下的全部队伍资产。
- 其他人员必须分别获得“查看运行资产”和“进入资产运维”权限。
- 只有查看权限时，可以查看资产状态，但不能创建远程会话。
- 创建会话时同时校验用户、比赛、队伍、运行环境和资产，不能使用一个资产的授权进入另一个资产。
- 所有角色的远程访问都进入审计，管理员不享受免审计通道。

权限判断通过 TeamLab 既有授权扩展点接入比赛权限组，TeamLab 核心不直接依赖比赛数据表。

## 4. 访问方式

### 4.1 容器

容器通过平台和节点服务之间的受控终端通道执行命令，不要求容器安装或开放 SSH。

### 4.2 Linux 虚拟机

Linux 虚拟机通过 Guacamole 提供网页 SSH。节点服务临时转发到目标资产配置的 SSH 端口。

### 4.3 Windows 虚拟机

Windows 虚拟机通过 Guacamole 提供网页 RDP。节点服务临时转发到目标资产配置的 RDP 端口，并保留现有剪贴板能力。

## 5. 运维账号配置

所有虚拟机统一称为镜像模板，不向用户展示额外镜像分类。模板提供两种运维账号方式。

### 5.1 平台自动创建账号

适用于能够接收平台初始化配置的镜像：

- Linux 为每个运行资产创建独立的随机运维身份和 SSH 密钥。
- Windows 为每个运行资产创建独立的随机管理员账号和密码。
- 凭据只属于一个队伍环境中的一个资产。
- 环境销毁时同步删除平台保存的运行凭据。

### 5.2 使用镜像已有账号

管理员在镜像模板的“运维访问”区域填写：

- 是否启用运维访问。
- 访问方式：SSH 或 RDP。
- 端口，默认分别为 22 和 3389。
- 用户名。
- 认证方式：密码或 SSH 私钥。
- 密码或私钥。

密码和私钥采用一次性写入控件。后端加密保存，保存后不回显；场景定义、正式版本、普通接口响应和日志只保存凭据引用，不保存明文。

### 5.3 可用性验证

- 镜像模板管理页提供“测试运维连接”。
- 场景试运行时自动进行一次真实登录验证。
- 正式队伍环境启动后再验证当前资产连接。
- 只有验证成功的运行资产显示“进入运维”。
- 失败时显示连接超时、端口不可达或认证失败等明确原因，不自动反复重试。

## 6. 会话链路

```text
管理员浏览器
  -> 主平台权限检查
  -> Guacamole 网页远程网关
  -> 计算节点临时转发
  -> 指定队伍环境中的指定资产
```

创建会话的流程：

1. 管理员选择比赛、队伍和资产，并填写访问原因。
2. 主平台校验权限和资产运行状态。
3. 主平台读取服务端加密凭据，不向浏览器返回凭据。
4. 目标计算节点创建只属于本次会话的临时 TCP 转发。
5. 转发只接受 Guacamole 所在可信地址的连接，并且只能连接指定资产和端口。
6. 主平台创建临时 Guacamole 连接并返回一次性网页会话地址。
7. 会话结束、超时或被强制终止后，平台删除 Guacamole 连接并关闭节点转发。

选手网络不包含计算节点管理地址，也不能访问临时转发端口。浏览器不获得资产地址、计算节点地址、密码、私钥或真实转发端口。

## 7. 会话控制

- 默认有效期 30 分钟。
- 使用中可以续期，每次续期重新检查权限和环境状态。
- 一个会话固定绑定一个资产和一种访问方式。
- 用户可以主动结束自己的会话。
- 管理员可以强制结束任意会话。
- 资产重置、销毁、比赛关闭访问或用户权限被撤销时，相关会话立即终止。
- 主服务重启后根据数据库记录清理过期会话；节点服务根据会话期限清理失联转发。

## 8. 审计

每次会话记录：

- 操作人员和权限来源。
- 比赛、队伍、运行环境和资产。
- SSH、RDP 或容器终端访问方式。
- 访问原因。
- 请求时间、连接时间、结束时间和来源地址。
- 正常退出、超时、权限撤销、资产销毁、管理员强制断开或异常中断等结束原因。
- 会话关联编号，供系统日志、部署事件和审计文件关联查询。

内容审计：

- SSH 和容器终端记录输入输出。
- RDP 记录会话画面。
- 审计文件记录大小、校验值、保存位置和到期时间。
- 默认保存 30 天，允许平台统一调整保存期限。
- 查看或下载审计内容需要独立的审计查看权限，并记录下载行为。
- 密码、私钥和远程网关管理令牌不得写入审计内容或普通日志。

## 9. 数据模型

### 9.1 镜像运维配置

保存访问方式、端口、用户名、凭据方式、加密凭据和最近验证结果。场景资产可以选择启用或禁用模板提供的运维访问，但不复制凭据明文。

### 9.2 运行资产凭据

只用于平台自动创建的资产级凭据，绑定运行环境、资产和环境代次。环境重置时生成新凭据，旧凭据随旧代次失效。

### 9.3 运维会话

至少记录会话编号、运行环境、资产、计算节点、访问方式、申请人、权限来源、状态、访问原因、创建时间、到期时间、结束时间、结束原因、临时转发编号和审计文件编号。

凭据不写入运维会话记录。

## 10. 服务边界

新增独立的资产运维访问服务，负责：

- 权限检查。
- 读取凭据。
- 创建和终止节点临时转发。
- 创建和删除 Guacamole 临时连接。
- 会话状态与超时回收。
- 审计记录和审计文件登记。

该服务通过 TeamLab 现有运行环境查询获取资产地址和所在节点，不修改场景编译、调度、网络建立、镜像分发或环境生命周期实现。

节点侧将现有 RDP 临时转发收敛为通用 TCP 转发，同时支持 SSH 和 RDP。容器终端继续复用容器命令执行能力，不经过 TCP 转发。

## 11. 管理接口

- 查询运行资产的运维可用状态。
- 创建运维会话。
- 查询会话状态。
- 获取一次性网页连接地址。
- 延长会话。
- 主动结束会话。
- 管理员强制结束会话。
- 查询会话审计记录。
- 下载终端记录或 RDP 录像。

这些接口属于平台管理接口，不进入选手接口，也不直接开放给外部访问令牌。后续如需外部安全运维系统接入，应增加独立权限范围和调用契约，不复用普通场景管理权限。

## 12. 界面

镜像模板页面增加“运维访问”配置和“测试运维连接”。

队伍资产列表显示：

- 未配置。
- 正在检查。
- SSH 可用。
- RDP 可用。
- 连接失败。
- 资产未运行。
- 正在运维。

有进入权限的用户可以填写访问原因并打开网页会话。会话页显示目标比赛、队伍、资产和剩余时间，并提供主动断开操作。管理端提供当前会话列表、强制断开和审计查看入口。

## 13. 验收要求

- 管理员和比赛所有者能够进入权限范围内的容器、Linux 虚拟机和 Windows 虚拟机。
- 被授予查看权限但未授予进入权限的人员无法创建会话。
- 没有相关权限的人员无法通过修改请求中的比赛、队伍、环境或资产编号越权。
- 浏览器请求和前端状态中不存在明文密码、私钥、节点地址和转发端口。
- 选手网络无法连接计算节点临时转发。
- SSH、RDP 和容器终端关闭后，节点转发和远程网关连接均被删除。
- 资产重置、销毁和权限撤销会立即结束相关会话。
- SSH、容器终端和 RDP 均产生完整审计记录，审计下载本身也被记录。
- 主服务或节点服务重启后，过期会话能够被准确回收，不遗留长期开放端口。

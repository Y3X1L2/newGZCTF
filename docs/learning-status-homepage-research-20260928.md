# 首页「个人学习状态」设计调研

调研日期：2026-09-28。选取六个有代表性的在线教学与安全训练平台，依据其官方公开帮助文档或产品说明整理；这是功能与信息层级研究，不是对登录后现行界面的逐像素实测。Coursera、Codecademy 等较早发布的资料只说明其公开设计思路，不保证今天的界面细节完全相同。

## 网站列表与观察

| 平台 | 官方资料中可确认的做法 | 对个人学习状态区的启发 |
| --- | --- | --- |
| [HTB Academy](https://help.hackthebox.com/en/articles/12256202-introduction-to-htb-academy) | 仪表盘展示安全领域完成比例、当前学习路径；可直接回到最近模块的上次阅读位置，未完成模块与内容发现分区呈现。 | 安全教育首页优先回答“我学到哪、下一步从哪继续”。 |
| [Codecademy](https://help.codecademy.com/hc/en-us/articles/1260801844089-Updates-to-your-Dashboard) | 首页突出最近学习的课程或路径，提供继续入口和每周目标；完整的在学、已完成清单放在“My Learning”。 | 首页只展示一个最相关的继续动作，详细记录另设入口。 |
| [Khan Academy](https://support.khanacademy.org/hc/en-us/articles/360030629852-What-is-my-Learner-Home-page-and-what-can-I-do-there) | 学员首页有课程、连续学习与等级进度；课堂活动优先呈现活跃项，并结合截止时间排序。 | 有明确任务时先提示下一项；习惯和等级只是辅助反馈。 |

| [edX](https://support.edx.org/hc/en-us/articles/360000340307-What-is-my-dashboard) | Dashboard 汇集已报名课程与项目，并展示起止日期、证书等信息；课程和项目分别进入详细页面。 | 首页状态宜简短，课程历史和完整进度留在详情页。 |
| [Duolingo](https://blog.duolingo.com/duolingo-score/) | 学习分数与到下一分数的进度条提供简明反馈，连续学习次数作为独立的习惯提示。 | 可用少量可解释的真实指标鼓励持续学习，不必把所有统计堆在一起。 |

## 调研结果

1. **动作先于数字。** 多个平台先给出最近课程、当前路径或待完成任务，再让用户查看统计。个人状态区的首要任务是降低“重新开始学习”的操作成本。
2. **进度需要上下文。** 单独的百分比不如“路径名称 + 已完成章节/总章节 + 下一节”容易理解；指标应能点进对应课程、技能或记录。
3. **短期反馈与长期成就分层。** 本周目标、最近学习时间适合首页轻量提示；完整学习轨迹、证书和历史课程适合详情页。
4. **首页保持克制。** 当前学习、课程推荐和完整清单不宜同权重排列。通知、赛事也应保持各自的信息边界，避免把个人状态做成综合仪表盘。

## 对本平台该板块的建议

沿用现有首页的简洁排版，将“学习脉络”置于左侧作为定位锚点；中间呈现**当前路径与下一步**（路径/课程名称、最近章节、可直达的“继续学习”）；右侧放**两项以内的真实进度反馈**（例如已完成章节、本周学习活动）。完整历史和技能细项通过“查看学习详情”进入二级页面。无真实字段时明确写“待补充（字段类型：最近章节 / 本周学习活动；内容方向：帮助回忆上次学习并决定下一步）”，不填虚构数字。文字允许换行，不能用省略号截断重要名称。

优先验证：用户是否能在首屏看懂上次学了什么、下一步点哪里；窄屏下是否仍能完整阅读路径名和操作文案。以上为设计推论，尚未对本平台现有数据字段或页面实现作验收。

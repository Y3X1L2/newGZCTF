# YINYU 文档入口

第一次了解项目，从 [项目概览与功能图](overview.md) 开始；了解某项功能，从 [模块目录](modules/README.md) 进入。模块的 README 讲用途和大体实现，development 给代码、契约和测试定位。

| 阅读目的 | 入口 |
| --- | --- |
| 看项目内容和功能关系 | [项目概览](overview.md) |
| 找某个功能的说明或代码 | [功能模块](modules/README.md) |
| 看当前进度、已部署范围与遗留问题 | [当前状态](current-state.md)、[后续事项](backlog.md) |
| 开发或修复功能 | [协作规则](../AGENTS.md) → 对应模块development → [共用架构](architecture/README.md)中的相关规则 |
| 部署、备份、回退或排障 | [运维入口](operations/README.md) |
| 接续一个复杂任务 | [活动任务与记录](records/README.md) |
| 写文档、拆分长页或处理自动检查 | [文档维护方法](architecture/documentation.md) |

日常阅读沿当前任务进入。`records/` 保存可追溯证据，`archive/` 保存历史材料，两者按任务定向查阅。实际操作以本次授权和重新核对的环境为准。

## 3. 阶段目标

管理员应能在同一个运维工作台中完成以下闭环：

1. 查看部署请求从等待、调度、执行到终态的全过程，并对允许取消的任务执行取消。
2. 跨节点查看 Docker、VM、渗透环境和 TeamLab 运行资源，并安全销毁后端明确支持的资源。
3. 查询历史系统日志，接收实时日志且不打断当前阅读位置。
4. 从运行概览发现节点、队列、实例、镜像和错误日志中的异常，并带着筛选条件进入对应页面。

阶段完成后，管理域的第一条纵向切片为：

```text
环境模板 -> 节点容量 -> 部署队列 -> 运行实例 -> 系统日志 -> 运行概览
```

- 不迁移旧 Mantine 管理页面，也不通过套壳或 CSS 隐藏复用旧页面。
- 不实现赛事、用户、理论题库、AWDP、Penetration 或 TeamLab 业务管理页。
- 不新增无事实来源的成功率、平均耗时和趋势图。
- 不把 `/api/admin/instances` 宣传为全域实例接口。
- 不在前端承担日志敏感字段脱敏责任。
- 不为了概览页复制队列、实例和日志的数据请求逻辑。
- 不在本阶段修改公共端视觉语言。

## 5. 实施顺序

严格采用以下顺序：

```text
5A-3.1 部署队列
    -> 5A-3.2 全域运行实例
    -> 5A-4.1 系统日志
    -> 5A-4.2 运行概览
```

运行概览最后实现。它只能组合前三个页面形成的 Adapter、Hook、选择器和 SWR 缓存，不能建立第二套统计口径。

## 6. 统一架构约束

### 6.1 数据流

```text
Route Page
  -> Domain Hook
    -> Domain Adapter
      -> runtimeJsonClient
        -> API
```

- 页面只负责布局、用户意图和视图状态。
- Hook 负责 SWR 键、轮询、缓存刷新、并发控制和异步操作状态。
- Adapter 负责路径兼容、参数转换、响应解析和统一错误模型。
- Presentation 文件负责状态、时间、类型、业务上下文和颜色语义映射。
- 页面和组件禁止直接调用 `fetch`、Axios 或生成客户端的易变命名空间。

### 6.2 文件边界

```text
src/vnext/features/admin/
```

文件可按实际复杂度合并，但必须满足：

- 页面文件目标不超过 350 行。
- 一个文件不同时承担 API 解析、轮询和页面渲染三种职责。
- 状态映射留在领域模块，不建立全平台万能状态函数。
- 共享抽象至少被两个真实页面使用后才能进入 `shared/`。

### 6.3 查询键

统一导出键工厂，禁止页面手写相似字符串：

```text
adminKeys.nodes()
adminKeys.nodeResources(nodeId, query)
adminKeys.queue(query)
adminKeys.globalInstances(query)
adminKeys.logs(query)
adminKeys.imageTemplates(query)
```

变更成功后只刷新相关键：

- 取消任务：队列列表、任务详情、运行概览。
- 销毁实例：全域实例、所属节点资源、节点摘要、运行概览。
- 合并实时日志：当前日志第一页，不触发历史页重复请求。

### 6.4 分页策略

后端目前存在两类分页，页面必须使用统一外观但保留真实语义：

1. 页码分页：URL 保存 `page`、`pageSize` 和筛选条件，支持刷新及前进后退恢复。
2. 游标分页：筛选条件保存在 URL，游标栈由 `useAdminCursorState` 管理；切换筛选时清空游标栈。
3. 游标过期或页面硬刷新后回到第一页，并显示一次轻量提示，不尝试伪造上一页游标。
4. 页码模式显示总数和页数；游标模式只显示当前页号及上一页、下一页，不显示虚假总数。
5. Adapter 使用可辨识联合类型返回分页模式，避免页面依赖 `null` 猜测契约。

## 7. 5A-3.1 部署队列 `/admin/queue`

### 7.1 事实来源

Adapter 兼容：

- 稳定服务器：`GET /api/v1/deployment-targets`，页码分页。
- 新版后端：`GET /api/v1/deployment-queue`，游标分页。
- 详情：`GET /api/v1/deployment-targets/{id}` 或 `GET /api/v1/deployment-queue/{id}`。
- 取消：`DELETE` 对应任务地址。

活跃状态：

```text
pending, scheduling, scheduled, running
```

终态：

```text
completed, failed, cancelled
```

### 7.2 页面结构

顶部指标：

- 当前加载结果数量。
- 当前页活跃任务。
- 当前页失败任务。
- 当前页占用 Docker 槽位。
- 当前页占用 VM 槽位。

如果接口提供 `total`，显示“共 N 条”；如果没有，只能标注“当前页”或“最近任务”。

筛选栏：

- 状态筛选由服务端执行。
- 关键词、资源类型和节点筛选只在后端契约支持时开放。
- 若首版只能筛选当前页，控件必须明确标注“筛选当前页”，不得让用户误认为是全局查询。
- 手动刷新和自动刷新状态放在筛选栏右侧。

表格列：

- 请求与业务上下文。
- 操作类型和资源类型。
- 目标节点。
- 状态及当前阶段。
- 队列位置或槽位。
- 等待/执行耗时。
- 错误摘要。
- 详情操作。

窄屏只保留请求、状态、节点和详情，其他字段进入详情抽屉，不产生页面级横向滚动。

### 7.3 详情抽屉

详情抽屉展示：

- 请求 ID、关联 ID 和资源标识。
- 所有者、比赛、题目、镜像和目标节点。
- Docker/VM 槽位。
- 当前阶段、阶段消息和阻塞原因。
- 创建、开始和完成时间。
- 错误全文和服务端结果。
- 由现有时间字段生成的事实时间线，不伪造不存在的阶段事件。

### 7.4 轮询与取消

- 当前页存在活跃任务时每 3 秒刷新。
- 当前页全为终态时每 15 秒刷新，页面隐藏时暂停。
- 窗口重新获得焦点时立即校验一次。
- 取消按钮只在服务端语义允许的活跃状态出现。
- 取消前使用 `VNextConfirmDialog` 显示任务、节点和潜在影响。
- 请求返回成功后将行标记为“取消确认中”，但不从列表删除。
- 等待服务端返回 `cancelled` 或其他终态；30 秒未确认时保留行并提示后台仍在处理。
- 同一任务取消进行中时禁用重复操作。

## 8. 5A-3.2 全域运行实例 `/admin/instances`

### 8.1 事实来源与降级

正式来源：

```text
GET /api/v1/nodes
GET /api/v1/nodes/{id}/resources?status=active
```

它覆盖 Docker、VM、渗透环境和 TeamLab，并包含节点、业务上下文、所有者、入口和生命周期。

降级来源：

```text
GET /api/admin/instances
```

该接口只包含传统比赛 Docker 容器。降级时页面必须持续显示“降级视图：仅传统比赛容器”，不能与节点资源结果静默合并。

### 8.2 聚合策略

- 先读取节点列表，再以最多 4 个并发请求聚合各节点活跃资源。
- 单节点超过一页时按服务端总数继续读取，单个节点内部顺序分页。
- 默认只读取活跃资源，避免进入页面就扫描所有历史记录。
- 单个节点失败时保留其他节点结果，并显示“已读取 X/Y 个节点”。
- 只有节点列表或所有节点资源契约均不可用时才进入传统容器降级模式。
- 资源唯一键使用 `nodeId:kind:id`，不以名称或运行时短 ID 去重。
- 历史模式首版要求先选择节点，再查询该节点历史；在没有全域历史 API 时不制作伪全局历史列表。

### 8.3 页面结构

顶部指标：

- 活跃实例总数。
- Docker、VM、渗透环境和 TeamLab 数量。
- 已读取节点数及部分失败状态。

筛选栏：

- 领域/资源类型。
- 节点。
- 活跃/历史。
- 所有者或业务上下文关键词。
- 手动刷新和数据来源状态。

表格列：

- 实例名称和类型。
- 所有者。
- 比赛、课程、题目或场景上下文。
- 所属节点。
- 公开入口。
- 开始时间和到期时间。
- 状态。
- 详情操作。

### 8.4 详情与销毁

详情抽屉展示完整资源字段和内部/公开入口。销毁能力按后端事实开放：

- Docker：`DELETE /api/admin/instances/{containerGuid}`。
- VM：`DELETE /api/v1/nodes/vms/{instanceId}/admin`。
- 渗透环境和 TeamLab：没有统一销毁契约时只显示来源和跳转，不显示无效按钮。

销毁流程：

1. 二次确认资源、所有者、节点和业务影响。
2. 请求成功后显示“销毁确认中”，禁止重复提交。
3. 每 2 秒读取该节点资源，直到资源停止或消失。
4. 最长等待 30 秒，超时后提示检查队列或节点，不假定销毁成功。
5. 确认终态后刷新全域实例、节点资源、节点摘要和概览缓存。

## 9. 5A-4.1 系统日志 `/admin/logs`

### 9.1 事实来源

- 历史查询：`GET /api/admin/logs`。
- 稳定服务器：数组响应，使用 `count/skip`。
- 新版后端：`items/nextCursor` 游标响应。
- 实时通道：`/hub/admin`，事件 `ReceivedLog`。

### 9.2 页面结构

顶部状态：

- SignalR 已连接、重连中或离线。
- 当前页记录数。
- 未合并实时日志数量。
- 当前查询级别。

筛选栏：

- 级别：全部、Information、Warning、Error。
- 状态、用户、IP 和关键词。
- 当前后端只支持级别查询时，其他条件明确标注为“筛选当前页”。
- 手动刷新和实时连接重试。

表格列：

- 时间。
- 级别。
- 用户和 IP。
- 消息摘要。
- 任务状态。
- 详情操作。

所有日志消息按 React 纯文本渲染。表格不使用 `dangerouslySetInnerHTML`。

### 9.3 实时缓冲

- SignalR 新消息先进入内存缓冲区，不直接插入表格。
- 页面显示“有 N 条新日志”，用户点击后合并并回到第一页。
- 有 ID 时按 ID 去重；无 ID 时用时间、用户、IP、消息和状态组成稳定键。
- 缓冲区最多保留 500 条，超出后记录丢弃数量并提示，不允许无限增长。
- 合并时再应用当前筛选，避免重复和顺序跳动。
- 离开页面时停止连接并移除事件处理器。
- 自动重连期间历史查询仍可使用；自动重连耗尽后提供手动重试。

### 9.4 详情抽屉

- 完整时间、级别、用户、IP 和状态。
- 完整消息正文，长文本独立换行和滚动。
- 稳定日志键或服务端 ID。
- 不展示未经服务端提供的“模块”或“节点”字段。
- 前端只负责显示，Flag、密码、Registry 凭据和 SSO Token 必须由服务端脱敏。

## 10. 5A-4.2 运行概览 `/admin/dashboard`

### 10.1 数据原则

当前没有正式聚合 API。首版概览只能组合已有事实来源：

- 节点列表和容量。
- 镜像模板总数和异常状态。
- 最近部署任务及其活跃/失败状态。
- 全域活跃实例或明确标记的部分聚合结果。
- 最近 Error 日志。

如果某个来源只有当前页或最近 N 条，标题必须写明范围。禁止把局部数据包装成全局成功率。

### 10.2 页面结构

顶部核心指标：

- 在线节点 / 节点总数。
- 可调度节点。
- Docker 可用槽位。
- VM 可用槽位。
- 活跃实例。
- 异常镜像或最近错误。

中部：

- 节点容量列表，突出离线、不可调度和容量高水位。
- 最近部署任务，显示活跃、失败和阻塞摘要。

底部：

- 异常或即将到期实例。
- 最近 Error 日志。

每个指标和列表标题都可点击跳转，并携带目标页支持的筛选参数。目标页不支持的参数不得写入 URL。

### 10.3 数据与错误隔离

- `useAdminDashboard` 只组合已存在的领域 Hook，不复制 API 请求。
- 使用同一 SWR 键时复用缓存，避免打开概览后产生重复请求风暴。
- 每个区域独立处理 Loading、Empty、Error 和 Partial 状态。
- 一个接口失败不能使整页崩溃，也不能把失败指标显示为 `0`。
- 节点资源聚合较重时使用缓存结果和延迟加载，不在每次渲染重新发起多节点请求。

## 12. 真实业务浏览器验收

### 12.1 无副作用验收

- 管理员登录后直接访问四个 URL，刷新后状态正常。
- 使用真实节点、镜像、任务、实例和日志数据核对字段。
- 切换筛选、分页、前进、后退和刷新。
- 打开和关闭详情抽屉，检查焦点、动画、滚动和长文本。
- 暂停 API 或模拟单接口失败，确认部分错误隔离。
- 断开网络后恢复，检查 SignalR 状态和历史日志可用性。

### 12.2 有副作用验收

以下操作会修改服务器状态，执行前必须使用专用测试数据：

1. 取消部署队列任务：任务会进入取消流程，可能终止尚未完成的实例创建。
2. 销毁 Docker 实例：测试容器会停止并释放端口。
3. 销毁 VM 实例：测试虚拟机会关停并释放节点槽位。
4. 生成实时日志：可通过创建并取消专用测试实例产生，不能操作演示或学员实例。

验收不以 HTTP 200 为完成标准，必须在队列、节点资源、实例列表和日志中观察到最终业务状态。

## 14. 性能与稳定性标准

- 多节点资源请求并发上限为 4。
- 页面不可见时停止高频轮询和无意义动画。
- 轮询请求未完成时不叠加同类请求。
- 日志缓冲最多 500 条，详情只在打开时渲染完整长文本。
- 筛选输入使用本地派生状态时不触发无关 API。
- 概览复用 SWR 缓存，不复制全域实例聚合。
- 控制台无未处理 Promise、React key、状态更新卸载组件等错误或警告。

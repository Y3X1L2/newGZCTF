# vNext 设计语言

页面应让使用者看清当前对象、状态、主要操作和操作结果。正式页面复用同一套壳层、语义颜色和组件，不因进入不同业务模块而重新学习导航。

## 层次与内容

- 全局导航用于切换功能，模块导航用于选择当前工作；主内容按用户任务组织。内部票据、摘要和资源ID放到需要它们的详情或诊断区域。
- 重复实体适合卡片；普通表单、正文和连续操作区优先使用留白、分隔线和网格，不做多层卡片嵌套。
- 列表和学习正文保持轻量。几何、Canvas或复杂动画只在明确需要表达拓扑或关系的区域使用，不成为全站背景负担。
- 真实状态使用文字配合颜色或图标；加载、空态、权限拒绝、失败和可重试状态分别表达。成功动画不能代替服务端结果。

## 主题、排版与密度

当前颜色、字体、间距、圆角与动画时间取自 [样式Token](style-tokens.md)。日间与夜间使用同一组语义名，切换主题不改变组件尺寸和信息层次。默认UI字体与等宽字体以源码为准，等宽字主要用于日志、代码、地址等内容。

保持正文和操作文字可读；窄屏优先换行、改变列数或在表格容器滚动，不通过持续缩小字体塞入内容。大屏增加可用空间和列数，不把所有文字按视口同比放大。

## 动效与可访问性

动效用于说明状态、层级和位置变化；避免全局`transition: all`及持续装饰动画。减少动效偏好下停止装饰，保留操作结果。菜单、表单和弹层须能用键盘访问，焦点清楚，关闭后回到合适的操作位置。

新页面使用vNext自身shared/design与CSS Module，不重新引入旧视觉组件、全局覆盖或Mantine。组件职责见 [组件边界](component-boundary.md)，真实页面路径见 [页面/API地图](page-api-map.md)。

## 设计检查

在390、1366、1920、2560宽度检查：主操作是否可见，正文是否重叠，是否有页面级横向滚动，加载前后是否明显跳动。再检查日夜主题、键盘与reduced-motion。接口、业务规则和权限保持真实，不为展示效果制造数据或隐藏失败。

本页是当前设计原则；历史参考站点研究、页面蓝图和当时建议参数按需追溯，不列为开发必读。新功能应先在所属模块说明用户任务，再选择现有组件实现。

# 任务交接模板

复杂或跨会话任务复制为 `docs/development/handoffs/YYYY-MM-DD-<task>.md`；计划与最终交接写在同一文件。短任务使用 PR/提交说明即可，删去不适用字段。

## 目标、范围与验收

- 用户目标 / 验收条件：
- 负责人（集成、审查、发布角色按需要注明）：
- 分支 / worktree / 起始 origin/main：
- 涉及模块、API、迁移与环境：
- 授权范围：仅记录动作与环境，不保存凭据，不继承旧任务授权。

## 计划与当前进度

- 工作状态：`in progress / blocked / complete`。
- 必要步骤（完成后勾选，避免复制流水）：
- 关键决定 / 兼容与安全不变量：
- 已完成 / 下一步 / 阻塞原因：

## 验证与交付

| 对象 | 命令或证据、提交与环境 | 状态 / 结果 |
| --- | --- | --- |
| 源码 / 契约 / 文档 | | |
| 定向 / 全量测试 | | |
| 实机 / 页面 / 生产 | | |

证据状态：`VERIFIED / IMPLEMENTED / NOT_RUN / BLOCKED / OPERATOR_ONLY`。说明未执行项及原因，旧测试结果不得代替当前提交。

- 最终提交：用实际 SHA；主记录同次提交无法自包含 SHA 时，用 `git log -1 -- <任务文件>` 找封存提交，禁止填写伪造或自引用 SHA。
- 推送 / PR / main 合入：
- 部署状态：未部署，或已部署的环境 / release / 实际组件身份。
- 备份 / 恢复 / 回退 / 冒烟（仅部署任务）：
- 当前状态 / 现行说明 / backlog 同步位置：
- 分支与 worktree：未合并前保留，合并与交接确认后清理。
- 遗留事项 / 下一位接手者第一步：

禁止记录密码、token、Cookie、私钥、Flag 或完整连接串。

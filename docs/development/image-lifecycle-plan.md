# 镜像分发、存储与回收改进计划

日期：2026-10-08。基线：`origin/main 2ba6e8d8`。本文是计划，不能作为已实现或已部署的证明。

## 目标与职责

普通导入、发布或启动不再让所有节点下载镜像；实际承载环境的节点才准备缺失镜像。主站保留目录、引用、调度与任务事实，节点直接从独立镜像存储读取制品，负责本机容量检查、运行和安全清理。不扩展主站 Agent 为所有节点的文件中转。

不要求主站长期保留上传源文件或冗余镜像副本。仍被题目使用的镜像必须有可靠、摘要固定的下载来源；删除最后一个运行实例不等于题目退役。独立 Registry 保存仍有业务引用的制品，退役后通过模板删除与受控 Registry GC 释放空间，不无条件永久保存。把唯一可重建来源放在可被随时驱逐的 Worker 缓存中不作为本期方案。

现有 `DeploymentQueueTicket`、分发记录、协调器、Registry 和 backing 检查继续复用，不建立第二套队列。原 PVE 虚拟机、快照、备份、旧发布和用户环境保持。大镜像、学习笔记、原始证据与凭据不进入 Git。

## 当前确认的问题

1. 普通 TeamLab 发布与创建会在调度之前向所有合格节点预分发；未承载实例的 `.31` 曾因此写满根盘。
2. 分盘调度预算不能保护这条旁路；下载没有按实际文件系统进行并发字节准入。
3. 普通排队销毁遗漏最后运行消费者释放 release 准备引用的接线；节点准备需求与业务制品保留需区分。
4. 模板删除有引用检查、节点清理和 `Deleting` 重试，但 Registry manifest 删除不立即释放 blob；当前没有自动 blob GC。
5. 前一轮 Windows 来宾网络读取失败缺少详细证据。它不能仅由 `.31` 满盘解释，也不能承诺镜像分发修复会一并解决。

## 分步交付

| 环节 | 具体交付 | 通过标准 |
| --- | --- | --- |
| 一：按需准备与安全释放 | 去掉普通导入/发布/创建的隐含全节点分发；已有部署链只准备已选节点；修销毁引用释放 | 未选节点无新下载；命中缓存不重下；销毁一个消费者不影响另一个；最后消费者正确释放运行需求 |
| 二：节点下载保护 | 实际文件系统并发准入、续传和缓存处理、写入余量守卫、可识别失败与预算释放 | 低空间在写满前拒绝；同盘并发不重复承诺容量；失败/取消无永久占用；VM/Docker限制如实记录 |
| 三：节点扩展与现场验收 | 核对 PVE 真实资源；为执行节点配置独立数据盘，必要时新增 KVM Worker；候选部署与至少两套环境验收 | 两套环境同时运行，记录节点/实例/代次；来宾网络与限定服务实际通信；销毁再建、重置及清理回读 |
| 四：回收闭环 | 冷缓存策略、临时文件对账、显式预热需求与保留期、主站暂存清理和受控 Registry GC | 不删运行或 backing 依赖；删除有原因和结果；可重试；报告实际释放字节而非仅元数据删除 |

第一批实现环节一、二中的必要能力和引用释放；不把尚未完成的 TTL、跨节点单一网络组调度或 Registry 自动 GC 包装为已交付。节点扩展服务于执行面容量，不以新增节点掩盖全节点分发缺陷。

## 代理分工与合入

- `codex/image-demand-distribution`：主站普通流程按需准备及受影响业务部署回归。
- `codex/image-agent-storage-guard`：Agent 容量准入、流式守卫与并发/续传/缓存行为测试。
- `codex/image-cache-reclamation`：正常销毁引用释放与回收策略、消费者保护测试。
- `codex/image-lifecycle-integration`：主会话维护计划，审查、整合、执行全量门禁；现场任务在实现审查后另分配。

并行代理使用不同 worktree，交叉文件先协调。整合前核对最新远端；源码、必要测试、工程文档一起提交。具体代码由子代理承担，主会话把握边界与验收。

## 现场验收与发布边界

先准备可识别且已推送的候选、备份与回退方案，再按用户要求请求部署确认。新增节点已经获得任务范围内授权；代码发布仍在候选可审查后确认。当前运行实例不擅自销毁。

验收优先使用现有两机 AD 场景和四机 VM118–121 场景，先核对它们各自的模板、资源与地址池。若采用同一场景的两份实例，必须明确地址分配与隔离条件，不能偷偷修改来宾业务或复用冲突 IP。两套指同时存在的独立环境，不是对同一个实例读两遍。

记录真实创建、网络回读、限定 TCP/HTTP、销毁再建和重置；未选节点文件及分发记录不新增。缓存回收、唯一制品保护与 Registry 空间回收分别验证。一个 `Ready` 状态或一个运行进程不等于生命周期验收通过。

## 本期不扩大的范围

同一网段资产拆到不同 Worker 的调度属于后续能力；现有不可分网络组仍需单节点承载。新节点可承载另一套环境，不能因此宣称已实现同组跨节点。旧 Windows 来宾读取诊断可在现场遇到明确阻碍时独立修正，不对写操作做盲目重试。

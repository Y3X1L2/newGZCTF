## 一任务一记录

复杂或跨会话任务复制 [模板](../task-handoff-template.md)，计划直接写在同一文件，阶段完成时更新；同一任务的开发、集成和发布由一个集成负责人汇总主记录，专项测试附件引用即可。短任务在 PR/提交说明中交接，无需创建空模板。

最少写清：目标与验收、负责人/分支/worktree/起点、已完成与下一步、代码/测试/实机证据的分别结论、提交与部署状态。任务工作状态用 `in progress / blocked / complete`；证据用 `VERIFIED / IMPLEMENTED / NOT_RUN / BLOCKED / OPERATOR_ONLY`，且必须说明验证对象，不能用一个 VERIFIED 覆盖全部环境。

任务完成后将稳定规则写回现行说明，遗留事项写入 backlog，主记录封存；保留当前发布、备份、回退和故障证据。长期无接手价值且被完整替代的过程材料可删除，独有证据才归档。禁止写凭据、Flag、完整连接串和未脱敏日志。

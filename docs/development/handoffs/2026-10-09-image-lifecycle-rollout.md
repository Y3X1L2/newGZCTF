## 历史资源恢复缺口

本批正常 API 已关闭旧四机运行和其他测试运行，旧 13 个非 Destroyed TeamLab 中 **12 个**销毁完成。最早 runtime 103 的冻结清理快照身份/digest一致，但服务器当前 Contracts 的真实 `IsValid` 返回 `DNS hostnames must be unique within each network`，因而正常清理被创建时的 DNS 校验阻断；状态仍需恢复，不直接写为 Destroyed。

- 设计文档将升级拆为工作流 A（高性能执行面，已验收）与工作流 B（功能控制面）。本轮承接 B 阶段剩余建设。

## 四、交付内容明细

### 4.1 第四层产品对象（第一轮，提交 5696c82）

- **设备包目录**：不可变 `(Name, Version)` 注册，承载 OCI/VM 制品引用、sha256 摘要、资源需求、端口声明、作者参数 schema、健康声明、协议事件类型；JSON 全部规范化存储（语义相等即字符串相等）；开放面只读，管理面登记/启停/归档。
- **现场连接器**：管理员登记的真实资源（6 种类型、控制范围授权边界、默认独占、显式共享容量）。独占性由数据库过滤唯一索引物理保证——`(ConnectorId, Slot)` 与 `(ConnectorId, RuntimeId)` 活动行唯一，并发竞争得到稳定 409 而非超卖；占用/释放幂等。
- **链路策略**：8 类策略（访问控制/NAT/带宽/时延/抖动/丢包/重复/断链），按类参数校验并规范化，声明式应用（同参数幂等、异参数 409 需先恢复）、手工恢复、定时恢复、销毁自动关闭；实体自带完整审计时间线。
- **资源池投影**：计算节点/模板/节点缓存（含 A 阶段用途引用计数）只读聚合，测试断言执行面地址与 Registry 凭据不出现在任何响应中。
- 生命周期 Worker（30 秒周期、批上限 200、全幂等）+ EF 迁移 `AddTeamLabCapabilityResources` + 6 个新 API scope。

### 4.2 工控与虚实结合全链路闭环（第二轮，提交 d8d6cdb）

1. **拓扑资产绑定**：`DevicePackageId`（FK Restrict）+ `DevicePackageParametersJson`（发布冻结）+ `ConnectorId`（公共 ID 引用、无 FK——归档连接器不破坏历史版本）。贯穿 v2 契约、编解码、结构校验（无包不带参、参数必须 JSON 对象）、应用校验（存在/启用/未归档/资产类型匹配）、发布摘要冻结与规划器漂移重校验（409）。
2. **规划事务内租约获取**：独占竞争失败即创建失败（`connector_occupied`）；后续规划失败随事务回滚；reset 走同 runtime 幂等语义。
3. **销毁同步收敛**：`FinalizeGenerationAsync` 在完全销毁时同步释放租约（`RuntimeDestroyed`）并关闭活动策略；代际重置保持租约与策略（真实接入不因重建丢失）。

### 4.3 外部 API 底座完备性（第二轮）

- 开放面：`POST scopes/{id}/archive`、`POST topologies/{id}/clone`（重校验镜像/设备包/连接器）、`POST releases/{id}/archive`（幂等）、`GET runtimes/{id}/captures`（游标）、远程会话四端点（`teamlab.remote-sessions:read/write`）、流量 `port` 结构化筛选。
- 管理面：设备包/连接器列表与详情、资源池快照、节点缓存、runtime 级链路策略管理。
- 稳定性与检测性：所有冲突路径返回稳定错误码（problem+json）；租约与策略实体自带审计事实；资源池暴露占用与引用计数供运维核对。

### 4.4 前端产品化交付（第二轮）

| 交付 | 产品决策 |

## 五、关键设计决策与责任边界

1. **平台不制作内容**：设备包登记只登记不可变制品引用与能力声明；镜像/制品内容、Sysprep、驱动安装归外部流水线。
2. **连接器按 ID 引用**：拓扑/发布只存公共 ID，不存地址或凭据；连接器归档不级联破坏历史版本；外部响应经测试断言零执行面信息泄露。
3. **同步写而非 ApiOperation**：租约占用/释放、策略应用/恢复是单事务控制面状态变更（无跨节点等待），用自然幂等（同对租约/同参数策略）替代幂等键，不产生悬挂 operation。
4. **执行面归属工作流 A**：链路策略与连接器挂载的 OVS/netem 物理执行未在本分支实现——进入冻结契约 `TeamLabExecutionPlanV2` 需按设计 §3.3 双方确认的独立小提交，不越界。
5. **审计载体**：策略/租约实体自带完整时间线（applied/recovered/origin、acquired/released/reason），不向事件表写第二份事实。

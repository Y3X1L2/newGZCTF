## 技术结论与改动

- 详情页不依赖场景草稿壳层，标题使用执行版本冻结名称；无场景来源仍可从全局运行路由管理。旧详情 tab 映射到新的任务视图，旧事件、日志、抓包入口进入高级排障，不自动启动抓包。
- 机器按运行网段列出，网卡显示本代次独立的分配配置及独立来宾回读。当前服务端没有可靠持久化回读时 `observed=null`，界面标明未核对，不以 `primaryIp` 或网段网关代替来宾网卡事实。
- 连接入口只按后端能力与协议开放。Windows 只显示适用 RDP/控制台，不显示 SSH/文件；未知系统不猜 SSH；Linux 与 Docker 显示各自适用工具。模板运维设置复用已有环境模板页，并提示存量环境新连接可能受影响。
- 业务端口集中在访问方式，显示目标机器/网卡地址、端口、外部地址及映射状态；映射不等于业务服务可达。VPN 读取、显式新增授权、下载现有配置、撤销分开。受管环境直接生命周期与入口修改受限。
- 操作记录默认时间线；高级事件、日志、会话审计、限时抓包按需打开。当前任务 API 不返回操作人和目标对象，页面明确说明，未伪造来源。
- 文件工具只在 Linux/Docker 能力具备时进入，保留上传覆盖和删除确认、原有服务端路径及权限校验；不再展示普通页面的运行时增删/替换机器、流量图、动态链路策略或完整目录树。
